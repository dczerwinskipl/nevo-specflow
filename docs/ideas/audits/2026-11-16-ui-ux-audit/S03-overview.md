# S03-overview: Specification Overview through its lifecycle

Evidence only, from the [UI/UX audit of 2026-11-16](../2026-11-16-ui-ux-audit.md). Images are on the
review-only branch `ux-audit/2026-11-16`, pinned to commit `9ddf6421`. Click a thumbnail for the
full image.

## Goal

Follow one Specification from “not started” through writing, Tasks, blocked/attention, completed and abandoned, and compare with the populated demo states and the Storybook early-state designs.

## Preconditions and data state

- **real-empty** (Real app on :4320, fresh scratch project (not demo); managed Sessions disabled): “SSO sign-in” (Feature, current folder). Workflow driven in the UI where possible (Start workflow, Finish step, Start next step, New task, Approve, Finish breakdown, Finish acceptance) and with the CLI for the rest (`workflow finish/start`, `tasks status … hold/resume`, Task Implement/Review). Documents were never edited (all stay “Template only”). Steps 19–20 use “Spike: passkeys” (Minimal), abandoned in the UI.
- **real-demo** (Real app, `start --demo` on :4319 (populated sample data, Sessions read-only/broken by design)): Demo Specifications covering draft, ready, active, three “requires attention” variants and an archived one.

## Steps: real-empty

Environment: Real app on :4320, fresh scratch project (not demo); managed Sessions disabled. Each step opens the URL in a fresh browser context at each device, then does the action described. Click a shot to open it; “full page” grows the viewport until the tallest scroll pane fits.

## Observations

Neutral notes only; severity is the audit’s estimate of impact on a person using the screen.

- **high** · all · The overview.md template sentence “Describe the intended outcome of this specification.” is shown as the Specification’s description under the title in every state, including Completed and Abandoned. <br><sub>Shots: `real-empty-*-01-not-started … 18-finished`</sub>
- **medium** · all · Design vs real, not started: layout and wording match the “Overview early states / Not started” story. The story always has a written goal under the title and a Sessions section with “New session”; the real project without a goal and with Sessions disabled has neither, and that case has no story. <br><sub>Shots: `storybook-desktop-specification-overview-early-states__not-started vs real-empty-desktop-01-not-started`</sub>
- **high** · all · A Task put on hold (with a reason) does not appear under “Requires attention”; the Overview only lists it under an “On hold” group and the reason is not visible there. <br><sub>Shots: `real-empty-*-13-blocked-held-task`</sub>
- **medium** · all · Overview: “Tasks appear when the workflow reaches Break the solution down (step 4 of 7).” Tasks page at step 4: “Tasks appear when … (step 4 of 7) finishes. Create tasks with New task, also before the workflow starts.” The two texts disagree, and the Overview offers no “New task”. <br><sub>Shots: `real-empty-*-10-step4-breakdown-no-tasks vs S04 03-tasks-empty-breakdown`</sub>
- **medium** · desktop · After “Start …” the page kept showing “Ready to start” with a dimmed button for at least 2.5 s; no progress text. <br><sub>Shots: `real-empty-desktop-08-step2-started`</sub>
- **medium** · all · Same person shown as “started by you” for UI actions and “started by domin” (OS user) for CLI actions. <br><sub>Shots: `real-empty-*-13-blocked-held-task`</sub>
- **medium** · all · All documents stay “Template only” through Completed; nothing on the NOW card links the empty documents to the step that should fill them. <br><sub>Shots: `real-empty-*-18-finished`</sub>
- **medium** · all · Demo Overview has no NOW/workflow card at all, while the project-mode Overview leads with it; the demo is not representative of the real screen. <br><sub>Shots: `real-demo-*-04-attention-agent-input vs real-empty-*-05-step1-requirements`</sub>
- **medium** · all · Task summary rows: demo shows the id twice (“TASK-07 TASK-07 · Uprawnienia…”); project mode shows “sign-in-screen Sign-in screen…” with no separator. On phone the line is cut with a trailing “...”. <br><sub>Shots: `real-demo-phone-04-attention-agent-input, real-empty-phone-13-blocked-held-task`</sub>
- **low** · all · Two “…” menus on the page (header “More actions” and NOW card “Workflow operations”) with different contents. <br><sub>Shots: `real-empty-*-02-not-started-more-actions / 03-not-started-workflow-operations`</sub>
- **low** · desktop/tablet · Breadcrumb middle item is the key in demo (“UI-1234”) and the title in project mode (“SSO sign-in”). Tablet portrait and phone drop the breadcrumb and show only “Overview”. <br><sub>Shots: `real-demo-desktop-04 vs real-empty-desktop-01`</sub>
- **low** · all · Demo group labels are Polish (“Implementacja”, “Ukończone 5”) inside the English UI. <br><sub>Shots: `real-demo-*-04-attention-agent-input`</sub>
