## Observations

Neutral notes only; severity is the audit’s estimate of impact on a person using the screen.

- **medium** · tablet, phone · On phone the Documents entry opens straight into overview.md; the file tree is only reachable through the header file switcher, and “Filter by type” could not be reached at tablet/phone widths. <br><sub>Shots: `real-demo-phone-01-documents-tree-and-reader, real-demo-*-07-tree-filter`</sub>
- **medium** · tablet, phone · The side panel opened from the Overview is 50/50 on desktop but becomes a full-screen page on tablet and phone, with the document title shown twice (header and H1). <br><sub>Shots: `real-demo-tablet-02-side-panel-from-overview`</sub>
- **low** · all · Tree order is alphabetical (overview, backend, behaviour, ux) while the Overview lists the same documents in archetype order (overview, behaviour, ux, backend). <br><sub>Shots: `real-empty-desktop-04-editor-template-doc vs S03 real-empty-desktop-01-not-started`</sub>
- **low** · all · Editor mode shows the YAML frontmatter as the first lines of every document. <br><sub>Shots: `real-empty-*-04-editor-template-doc`</sub>
