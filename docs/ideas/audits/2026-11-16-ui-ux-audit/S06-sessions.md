## Observations

Neutral notes only; severity is the audit’s estimate of impact on a person using the screen.

- **medium** · all · “Sessions are turned off in this project.” is the whole page: no reason, no pointer to the setting, while the nav item stays visible. <br><sub>Shots: `real-empty-*-01-sessions-disabled`</sub>
- **medium** · all · Demo session page contradicts itself: header “Response required”, body “This session has no messages.”, footer “You can only view this session.” The page also never reaches network idle. <br><sub>Shots: `real-demo-phone-03-session-detail-demo`</sub>
- **medium** · phone · Storybook Full Session on phone: the floating round menu and “…” buttons sit on top of the conversation text at the top edge (text runs underneath them). The story renders in Polish (“Nie powiodło się: 1 uruchomienie testów”), unlike the English app. <br><sub>Shots: `storybook-phone-managed-session__default`</sub>
- **low** · desktop · New session (demo): “Local adapter” card text is Polish (“Niedostępny w tym środowisku demonstracyjnym.”); the composer placeholder says “Choose the agent and start the session” while an agent is already selected. <br><sub>Shots: `real-demo-desktop-04-new-session-demo`</sub>
