## Observations

Neutral notes only; severity is the audit’s estimate of impact on a person using the screen.

- **critical** · all · Close is a dead end in a project made from the example config: the dialog says “Ready to close”, and confirming shows “Close cannot start now — The workflow did not change. Try again.” next to the green “Ready to close”. The CLI names the real causes: untracked Specification files, then “requires explicit git.integrationTargetBranch configuration”. Neither appears in the UI. <br><sub>Shots: `real-empty-desktop-17-close-confirmed, real-empty-*-18-close-retry-clean-checkout`</sub>
- **high** · all · On a retry the “Close specification” confirm stays disabled for 8+ seconds with no explanation, then the same error appears without a click. <br><sub>Shots: `real-empty-*-18-close-retry-clean-checkout`</sub>
