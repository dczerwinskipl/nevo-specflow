## Observations

Neutral notes only; severity is the audit’s estimate of impact on a person using the screen.

- **medium** · all · Switching Specification from the Tasks page opens the other Specification’s Overview, so the person loses the page they were on. <br><sub>Shots: `real-demo-*-04-switch-to-other-spec`</sub>
- **low** · all · In the drawer the current Specification title is cut with a trailing “…” on every width (“Deterministic admission an…”). <br><sub>Shots: `real-demo-phone-03-spec-switcher`</sub>
- **low** · tablet, phone · Phone/tablet headers show a back arrow on Task and Document pages but a hamburger on Overview; tablet portrait drops the breadcrumb entirely. <br><sub>Shots: `real-demo-phone-06-task-header-back`</sub>
