Neutral notes only; severity is the audit’s estimate of impact on a person using the screen.

- **high** · all · Plain Markdown files are all skipped (“missing frontmatter”); the required fields and allowed types are only revealed one error at a time, so a person fixes the same files several times before anything shows. <br><sub>Shots: `real-empty-*-04-docs-all-skipped-expanded`</sub>
- **medium** · all · Demo Documentation says “cannot be read right now … Try again in a moment” with Retry, although in demo it can never load. <br><sub>Shots: `real-demo-*-01-docs-home-demo`</sub>
- **low** · all · Search snippets show raw Mermaid source (“U->>W: Open sign-in”). <br><sub>Shots: `real-empty-phone-07-docs-search-results`</sub>
- **low** · phone · The skipped-files warning stays at the top above the search field on phone, pushing results down. <br><sub>Shots: `real-empty-phone-07-docs-search-results`</sub>
